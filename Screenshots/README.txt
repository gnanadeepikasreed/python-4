
# Multi-Plan Telecommunications Cost Optimization

## Description
This project compares different mobile plans based on the user's monthly data, call minutes, validity, and budget requirements.

## Features
- Accepts user requirements.
- Accepts multiple mobile plans.
- Compares plan prices.
- Checks data and call requirements.
- Identifies suitable plans.

## Concepts Used
Variables, operators, conditional statements, loops, strings, and lists.

## Language
Python 3

## How to Run
python telecom_plan_optimization.py
